## 📖 عن اللعبة

**مشاعر** لعبة كروت تفاعلية اتصممت للأزواج، فكرتها بسيطة وجميلة: اختاروا فئة الأسئلة اللي عايزينها (أو العبوا كل حاجة مع بعض)، اقلبوا الكرت، واتكلموا. مش مجرد أسئلة عابرة — دي أبواب لمحادثات ممكن ما كنتوش هتوصلولها من غير سبب يفتحها.

سواء بتدوروا على لحظة رومانسية، ضحكة سريعة، كلام عميق، أو مجرد فضول عن يوميات بعض — فيه فئة ليها.

المشروع صفحة واحدة (Single File) شغالة بالكامل Offline، من غير Backend ولا تثبيت ولا حتى اتصال إنترنت بعد أول تحميل (باستثناء الخطوط).

## 🚀 طريقة التشغيل

اللعبة صفحة واحدة، من غير أي متطلبات أو تثبيت.

### تشغيل مباشر

```bash
git clone https://github.com/MRxAlc0h0lic/Mashaeir-game.git
```

بعدها افتحوا `index.html` في أي متصفح، وخلاص.

### أو جرّبوها أونلاين

استضيفوا الملف مباشرة بـ **GitHub Pages**:

1. من إعدادات الريبو (Settings) ← Pages
2. اختاروا الـ Branch: `main` والمجلد: `/root`
3. احفظوا، وهيبقى عندكم رابط مباشر للعبة تقدروا تبعتوه لبعض

## 🕹️ طريقة اللعب

1. من الشاشة الرئيسية، اختاروا فئة الأسئلة (أو "كل الأسئلة" للتجربة الكاملة)
2. دوسوا **ابدأ اللعبة ✨**
3. دوسوا على الكرت عشان يتقلب ويظهرلكم السؤال
4. استخدموا **التالي / السابق** للتنقل، أو **خلط** لترتيب جديد كل مرة
5. لما تخلصوا كل الأسئلة، هتظهر شاشة نهاية بتهنئكم على الرحلة 🎉

جربوا زرار 🌙 في أعلى الشاشة لو حابين تلعبوا بالدارك مود — مثالي لجلسات الليل الهادية.

كمان تقدروا تدوسوا **تصفح الأسئلة** من الشاشة الرئيسية لو عايزين تستعرضوا كل الأسئلة مقسمة حسب الفئة من غير ما تدخلوا وضع اللعب.

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| **HTML5** | هيكل الصفحة بالكامل |
| **CSS3** | كل التنسيقات، الأنيميشن (Flip Cards)، ونظام الثيمات عبر CSS Variables |
| **JavaScript (Vanilla)** | منطق اللعبة، إدارة الحالة، والدارك مود — بدون أي مكتبة خارجية |
| **localStorage** | حفظ اختيار الوضع (فاتح/غامق) بين الزيارات |
| **Google Fonts** | خطوط `Amiri` و `Tajawal` لتجربة عربية أنيقة |
